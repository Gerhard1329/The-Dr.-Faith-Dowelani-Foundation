# Dr. Faith Dowelani Foundation Website

A responsive, modern one-page foundation website built with plain HTML, CSS and JavaScript.

## Files
- index.html — website structure/content
- styles.css — responsive visual design
- script.js — mobile navigation and subtle scroll reveals

## Run locally
Open `index.html` in a browser.

## Publish
Upload all three files to the public web root of your hosting account (for example, `public_html`) and make sure `index.html` is the default document.

## Content note
The website uses the Foundation's CIPC registration details and the September 2026 project proposal as source material. Programme items are presented as an establishment/launch framework rather than as completed operational programmes unless explicitly stated.

## Logo
The approved Foundation emblem is in `assets/` (logo-icon.png for the header/footer mark, logo-full.png with the full wordmark for other uses) with favicon variants generated from it.
